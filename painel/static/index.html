Reiniciar servidor

Avisa os jogadores, salva o mundo e desliga com contagem. O Docker religa tudo automaticamente em seguida.

Zona de perigo

Aviso aos jogadores, save e desligamento com contagem. Como o container usa restart: unless-stopped, o Docker religa sozinho — para deixar offline de verdade, pare pelo CasaOS.

Emergência

Encadeia em uma ação: anúncio → save → backup do mundo → desligamento. Use só quando realmente necessário — operações concorrentes são bloqueadas durante a execução.

Console do painel ao vivo

Eventos internos do painel: acessos, ações administrativas, quedas do servidor, configurações e bans. A REST API do jogo não expõe logs — este console mostra a atividade observada pelo painel.

Backups do mundo

Zips do jogo (cron do container) e do painel (palworld-painel-*, criados sob demanda ou pela Agenda). Restaurar troca a pasta de saves — o estado atual é preservado e o servidor reinicia depois.

Auto-recuperação

Se o FPS ficar abaixo do mínimo pela janela configurada, o painel anuncia, salva e reinicia graciosamente. Cooldown e limite diário impedem loop infinito.
